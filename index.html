La idea

Hasta ahora usáis Claude en el navegador: cada conversación empieza de cero, y lo que decidís se queda perdido en el chat. Así trabajamos nosotros en mi empresa, y es lo que os enseñé en la llamada: una casa. Una carpeta en vuestro ordenador, con una copia segura en GitHub, donde vive todo el negocio. Claude trabaja dentro de esa carpeta: la lee, la ordena, escribe en ella y construye desde ella. Así cada conversación empieza sabiendo dónde estáis, y nada se pierde.

Empieza así de sencilla:

vuestro-negocio/ ├── CLAUDE.md el manual que Claude lee al empezar └── estado.md la pizarra: qué está pasando y qué viene

Lo demás lo diseñaréis vosotras con Claude, cuando ya hayáis trabajado unos días en ella. Cada persona se organiza a su manera: unas en listas, otras por proyectos, otras por frentes de trabajo o por clientes. Claude os preguntará cómo pensáis y qué queréis tener a mano, y la casa crecerá con vosotras: un cajón nace cuando hace falta, con el nombre que le pongáis.

La casa
Esa carpeta. Todo el negocio, en archivos de texto que podéis leer y que Claude puede leer.
El manual
CLAUDE.md: lo que Claude lee al empezar cada conversación. Quiénes sois, cómo os gusta trabajar, dónde está cada cosa.
Las sesiones
Varias conversaciones con Claude a la vez, cada una con su papel: una para pensar y decidir, otras para construir.
La caja fuerte
GitHub: una copia de la casa en internet, con todo el historial. Las dos trabajáis sobre ella sin pisaros.

Antes de empezar

  • Un plan de pago de Claude para cada una (Pro o Max). Esther ya lo tiene; Eva, si aún no, se contrata en claude.ai.
  • Vuestra cuenta de GitHub, la que ya usáis, y saber cuál es el repositorio de vuestra web.
  • Unas dos horas tranquilas para la primera sesión, con el ordenador enchufado.
  • Quién empieza: Esther. Eva puede estar delante desde el principio, y hará estos mismos pasos en su Mac cuando Claude os lo diga.

Paso a paso

Elige tu ordenador y los pasos se ajustan:

  1. Instalar VS Code

    Entra en code.visualstudio.com/download y descarga la versión para tu ordenador.

    • Abre el archivo descargado y arrastra Visual Studio Code a la carpeta Aplicaciones.
    • Ábrelo desde Aplicaciones. El Mac preguntará si estás segura de abrirlo: di que sí.
    • Truco: con VS Code abierto, clic derecho en su icono del Dock → Opciones → Mantener en el Dock.
    • Elige el instalador User Installer y ábrelo.
    • En las opciones, marca la de añadir «Abrir con Code» al menú de las carpetas, y deja marcada la de añadir a PATH.
    • Si aparece una pantalla sobre GitHub Copilot CLI, elige no añadirlo: es otro producto.

    Si VS Code os ofrece ponerse en español, podéis aceptar: los menús cambian de nombre, y aquí os damos los dos.

  2. Instalar Claude Code dentro de VS Code

    • Abre Extensiones (Extensions) con Cmd ⌘Ctrl + Mayús ⇧ + X.
    • Busca Claude Code y elige «Claude Code for VS Code», de Anthropic. Pulsa Instalar.

    No hace falta instalar nada más. Si no aparece, cierra VS Code y vuelve a abrirlo.

  3. Crear la carpeta de vuestra casa

    • En el Finder, ve a tu carpeta de usuario (menú Ir → Inicio) y crea una carpeta llamada Proyectos. Dentro, otra con el nombre de vuestro negocio (o casa, por ahora).
    • En el Explorador de archivos, en C:\Usuarios\tu-nombre, crea una carpeta llamada Proyectos. Dentro, otra con el nombre de vuestro negocio (o casa, por ahora).
    • En VS Code: Archivo → Abrir carpeta… (File → Open Folder…) y elige esa carpeta.
    • Si pregunta si confías en los autores de la carpeta, di que sí: si no, Claude no funciona.

    Importante: no la pongáis dentro de Documentos ni del Escritorio. En muchos Mac, iCloud los sincroniza y eso hace que Git (la copia en GitHub) se cuelgue.

    Importante: no la pongáis dentro de una carpeta que sincronice OneDrive (Documentos o Escritorio, a veces): eso hace que Git se cuelgue.

    ¿Ya tenéis vuestro repositorio de la web en este ordenador? No pasa nada: empezad igualmente en esta carpeta nueva. Claude lo revisará con vosotras y decidiréis juntas cómo encaja.

  4. Guardar las instrucciones para Claude

    • Más abajo, en Instrucciones para Claude, pulsa Copiar las instrucciones.
    • En VS Code, en el explorador de la izquierda, pulsa el icono de archivo nuevo (una hoja con un +) y llámalo EMPIEZA-AQUI.md. Pulsa Intro.
    • Pega con Cmd ⌘Ctrl + V y guarda con Cmd ⌘Ctrl + S.

    Es un texto largo a propósito: es el manual de vuestro guía. No hace falta que lo leáis entero (aunque podéis).

  5. Abrir Claude e iniciar sesión

    • Con el archivo abierto, pulsa el icono de la chispa arriba a la derecha, o ✻ Claude Code abajo a la derecha.
    • La primera vez sale una pantalla para iniciar sesión: pulsa Sign in, se abrirá el navegador, entra con tu cuenta de Claude y autoriza. Vuelve a VS Code.

  6. Poner Claude en modo Manual (para aprender)

    • Abajo del cuadro donde se escribe hay un indicador del modo. Pulsa y elige Manual.
    • Así Claude os pedirá permiso antes de cambiar nada, y veréis cada cambio como un «antes y después».

    Más adelante, cuando os fieis, Claude os explicará los otros modos.

  7. Escribir la primera frase

    En el cuadro de Claude, escribe (o copia) esto y pulsa Intro:

    Lee el archivo EMPIEZA-AQUI.md y empecemos. Copiado

    Desde aquí, Claude os guía. Os preguntará quién está delante, qué ordenador usáis y qué tenéis ya, y os irá enseñando paso a paso. Id a vuestro ritmo.

Pulsa el botón y pégalo en el archivo (paso 4).

Cómo trabajar con Claude

  
    
    
  • Habladle como a alguien del equipo, con contexto. En vez de «haz una web», mejor: «Queremos una página para presentar la idea X a clientes Y; mira contexto/empresa.md».
    • 
    
  • Pedid opciones y su recomendación: «dame dos o tres opciones y dime cuál elegirías y por qué».
    • 
    
  • Si no entendéis algo, decidlo. «Explícamelo más fácil», «ve más despacio». Para eso está.
    • 
    
  • Claude os explicará cada término nuevo hasta que le digáis que ya no hace falta («ya no hace falta que me lo expliques»). Cada una a su ritmo.
    • 
    
  • Antes de aceptar un permiso que no entendéis, preguntad: «¿qué vas a hacer exactamente?».
    • 
    
  • Lo importante, a la casa: «apúntalo en decisiones», «añádelo a tareas». Lo que solo está en el chat se olvida.
    • 
    
  • Una tarea por conversación cuando se construye algo. Al terminar, se cierra y se abre otra.
    • 
    
  • Si se lía, pulsad Esc para pararlo y volved a pedirlo más corto.
    • 
    
  • Para dar un archivo, escribid @ y su nombre, o arrastradlo al cuadro con Mayús ⇧ pulsada. También podéis pegar capturas de pantalla.
    • 
  






  
La rutina

  
Tres tipos de conversación, como hacemos nosotros:

  

    

      
TipoPara quéCuánto dura

      
        
DirecciónPensar, decidir, planear. De aquí salen los «encargos» para construir.Días: es la misma conversación a la que volvéis.

        
ConstrucciónUna tarea concreta: una página, un cambio en la web, un documento largo.Lo que dure la tarea. Luego se cierra.

        
RápidaUna pregunta o un cambio pequeño.Minutos.

      
    

  

  
Al empezar, decid «empezamos»: Claude trae los cambios de la otra, lee la pizarra (estado.md) y os dice por dónde vais.
Al terminar, decid «cerramos la sesión»: Claude pone la casa al día, os hace un resumen y guarda la copia en GitHub.

  
Para abrir otra conversación a la vez: en la paleta de comandos (Cmd ⌘Ctrl + Mayús ⇧ + P) escribid «Claude Code: Open in New Tab». Claude os lo enseñará con calma.






  
Lo que nunca

  
    
    
  • Nunca pegues contraseñas ni claves en el chat. Si Claude necesita una clave, os dirá dónde ponerla: en un archivo que GitHub no ve.
    • 
    
  • No aceptes un permiso que no entiendes. Pregunta primero; Claude te lo explica.
    • 
    
  • Nada se publica sin vuestro visto bueno. Claude os enseñará primero una versión de prueba.
    • 
    
  • La casa, fuera de iCloud y OneDrive. En una carpeta como Proyectos, como en el paso 3.
    • 
  






  
Glosario

  

    
VS Code
El programa donde trabajaréis: muestra vuestros archivos y tiene a Claude dentro.

    
Claude Code
Claude trabajando dentro de vuestra carpeta: puede leer, escribir y construir, siempre con vuestro permiso.

    
Extensión
Un añadido que se instala dentro de VS Code. Claude Code es una.

    
Archivo .md
Texto normal con títulos y listas (se llama Markdown). Casi toda la casa son archivos así.

    
CLAUDE.md
El manual de la casa para Claude. Es vuestro: podéis cambiarlo cuando queráis.

    
Encargo
Una nota corta que dice qué hay que construir, por qué y cómo sabremos que está bien.

    
Repositorio
Una carpeta con historial: recuerda cada versión de cada archivo.

    
GitHub
La web donde se guarda la copia del repositorio. Vuestra caja fuerte compartida.

    
Commit
Guardar una «foto» del estado de la casa, con una nota de qué cambió.

    
Push y pull
Subir vuestras fotos a GitHub, y traer las de la otra.

    
Clonar
Hacer una copia del repositorio en tu ordenador, conectada a GitHub.

    
Skill y plugin
Manuales especializados que Claude sigue para un tipo de trabajo, como un recetario profesional.

    
impeccable
Una skill de diseño para que vuestras webs se vean profesionales, no hechas «por una IA cualquiera».

    
Supabase
La base de datos en la nube que ya usáis. Sus claves secretas nunca van en el chat ni en la casa.

  






  
Preguntas

  
¿Y si me equivoco o rompo algo?
Casi todo tiene arreglo: la casa guarda historial en GitHub, y en modo Manual Claude os pide permiso antes de cambiar nada. Si algo sale mal, decídselo a Claude tal cual: «creo que he roto algo».

  
¿Cuánto lleva el arranque?
Unas seis a diez sesiones de una o dos horas, a vuestro ritmo. Claude lleva un archivo de progreso, así que podéis parar cuando queráis y retomar otro día.

  
¿Qué pasa si cierro VS Code a mitad?
Nada. Las conversaciones se pueden recuperar (botón de historial, arriba del panel de Claude), y lo importante ya está escrito en la casa.

  
¿Eva tiene que hacer todo esto también?
Sí, los pasos 1 a 7 en su Mac, cuando Claude os lo indique (es una fase del arranque: «Dos personas, una casa»). Puede estar delante desde el primer día.

  
¿Puedo seguir usando Claude en el navegador?
Para cosas sueltas, sí (por ejemplo, desde el móvil). Pero el trabajo del negocio, en la casa: es lo que hace que nada se pierda.

  
¿Cuesta dinero?
El plan de Claude de cada una. VS Code y GitHub, para esto, son gratis. Publicar webs puede tener coste según el servicio: Claude os lo dirá antes de nada.

  
Algo de esta guía no coincide con lo que veo
Los programas cambian a menudo. Haced una captura de pantalla, pegadla en el chat de Claude y preguntadle: os orientará.
